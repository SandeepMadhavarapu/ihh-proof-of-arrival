# Immigrant Hall of Honor — optional standalone demo

Twenty-one pages. 530 KB of HTML, CSS, scripts and text; portrait and archival image files in `media/` additional. No framework, no build step, no third-party request, no tracking.
Open `index.html` in any browser. There is nothing to install.

This is a supplement/pilot demonstration, not a museum-site replacement. See
[POSITIONING.md](../POSITIONING.md) and [ROADMAP.md](../ROADMAP.md).

`sitemap.xml` and `robots.txt` are generated by `tools/build_site_meta.py` for the demonstration
address; robots.txt keeps this student prototype out of search engines. Change both before any
production deployment.

## The documents

- **`FINDINGS.md`** — the audit of the live site, the interactive, the refusal, and the limits.
- **`TESTS-RUN.md`** — what was tested, with results, what has *not* been tested, and the nine
  defects an independent audit found after this site passed its own suite.
- **`qa/`** — the test harnesses in `../qa/`, with a note on what each one caught.
- **`../inductees/<name>/media-manifest.csv`** — every item on each profile: source, rights statement word for word,
  credit line, alt text written after viewing the image, and whether we recommend using it.

## Adding a sixth case file

`cases.py` holds the data; `gen.py` renders `verify.html` from it. A case file is a list of
claims, each with its evidence, a verdict and the reasoning. Editing this Python data source requires appropriate technical support. Run `python3 gen.py`.

Never hand-edit generated `verify.html`. Edit `cases.py` and regenerate; a technical
maintainer must support staff who cannot run that workflow.

## What is deliberately unfinished

Three `slot` blocks are marked in the markup — the capital campaign facts, the leadership roster
and the analytics disclosure. **We will not invent an EIN, a fundraising goal or a board list.**
Nine of the ten inductee profiles are unwritten. Six image files are not downloaded.
